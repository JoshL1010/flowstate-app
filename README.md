# FlowState

A native macOS workspace launcher. It waits at the edge of the screen and opens the
editor, terminal, repository and pages a project needs — arranged — in one keystroke.

**[Download the beta](https://github.com/JoshL1010/flowstate-app/releases/latest)** ·
macOS 15 or later · Apple silicon and Intel · free while in beta

This repository holds the website and the released builds. FlowState's source is not
public.

## Privacy

FlowState has no account, no analytics, no telemetry, no third-party SDKs and no server.
Projects, paths and preferences are files in your own Application Support folder.

Accessibility permission is optional and only used to move and resize windows. Automation
is requested only if you ask a workspace link to open in a new Safari or Chrome window.
Both can be revoked at any time in System Settings.
