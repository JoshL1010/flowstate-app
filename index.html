Five minutes from download to your first launch.

FlowState is signed with a Developer ID certificate and notarized by Apple, so it opens with a double click like anything else. No right-click trick, no warning to dismiss, no Terminal.

    Drag FlowState to Applications and open it. It has no Dock icon and no window — it lives at the edge of the screen, so the first launch shows you where.

Questions worth answering before you download it.

These are the ones testers actually asked. If yours is not here, ask it — support@flowstatemac.com reaches one person.

Is it really free at the moment?

Yes, and completely. During the beta every feature is unlocked, no trial clock is running, there is nothing to buy and no card is asked for. When that changes it will be announced first, not switched off one morning.

What does it actually do that Spaces or Stage Manager does not?

Those arrange the windows you have already opened. FlowState opens them. One keystroke starts the editor on the right folder, a terminal already in that directory, the repository and the pages that project needs, and puts them where you want them — from nothing.

Does it work with my editor and my terminal?

It launches whatever is on your Mac, so anything you can open from Finder works — Xcode, VS Code, Cursor, Zed, JetBrains, Terminal, iTerm, Ghostty, Warp. Nothing needs a plugin, because FlowState opens applications rather than integrating with them.

Why does it want Accessibility access?

That permission is the only way macOS lets one application move another one’s windows, which is what the arranging is. It reads window positions to put them back and nothing else is recorded or sent.

Declining it is a real option: everything still opens, it just opens wherever macOS would have put it. You can grant it later in System Settings without reinstalling.

Why is it not on the Mac App Store?

Because the App Store requires a sandboxed build, and the sandbox forbids moving other applications’ windows — there is no entitlement that lifts it. An App Store version of FlowState could not arrange anything, which is most of the point of it. Downloading it here gets the whole application, signed with a Developer ID certificate and notarized by Apple.

How do updates work?

FlowState checks for a new version and offers it to you. Every update carries a signature made with a key that only the release machine holds, so an installed copy will refuse a build that did not come from here even if the download itself were tampered with. The check can be turned off in Settings.

Does it work with more than one monitor?

It runs, and it is honestly not tested well on multiple displays yet — arrangement is written against the screen the panel is on. If you use several, that is exactly the report worth sending.

What happens to my projects if I stop paying, or if FlowState stops?

They stay. Everything you configure lives in plain files in your own Application Support folder, not in an account and not on a server. The free tier keeps two projects working; the files for the rest are still there and still readable, and come back the moment a subscription does.
